# Stacked Horror – ke stažení

Co-op střílečka ve tmě pro 1–4 hráče (lokálně i přes internet). Vlny zombíků, vylepšení z truhly,
bossfight a na konci souboj každý proti každému.

## Stažení
Nejnovější verze je v **[Releases](../../releases/latest)** – stáhni `StackedHorror-…-windows.zip`,
rozbal a spusť `StackedHorror.exe`. Nic se neinstaluje.

Windows může ukázat „Systém Windows ochránil váš počítač“ (hra není podepsaná):
„Další informace“ → „Přesto spustit“.

## Hra přes internet
1. Hostitel klikne na **HOSTOVAT** a pošle ostatním **KÓD**, který se ukáže dole.
2. Ostatní napíšou kód do pole vpravo dole a kliknou na **PŘIPOJIT**.
3. Hostitel dá **START**. Všichni musí mít stejnou verzi.

Návod s ovládáním je v zipu (`JAK_HRAT.txt`).
